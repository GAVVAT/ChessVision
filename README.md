# ChessVision

Стартовый Android-проект для учебного анализа шахматных позиций.

## Сборка без компьютера
После загрузки файлов в GitHub открой вкладку **Actions** и запусти workflow **Android debug build**. APK появится в Artifacts после успешной сборки.

## Важно
Это только каркас проекта. Пока реализован запрос разрешения на захват экрана и заготовка UCI-класса. Ещё НЕ реализованы распознавание шахматной доски и фигур, преобразование позиции в FEN, встроенный бинарный файл Stockfish, разбор лучшего хода и плавающее окно. Следующие этапы разработки добавят эти функции.

Проект предназначен для анализа учебных позиций, задач и завершённых партий, а не для скрытых подсказок во время рейтинговой онлайн-игры.
